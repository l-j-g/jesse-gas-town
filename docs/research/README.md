# Research Notes

Use this folder for strategy hypotheses, market-regime notes, imported public examples, and research synthesis.

Initial focus:

- 1h moving-average trend following
- golden cross / MA crossover
- 3 moving average trend strategy
- later: multi-timeframe confirmation, regime filters, and conviction-weighted allocation

Required for each strategy idea:

- edge thesis
- target regime
- failure regime
- entry trigger
- exit and risk model
- first validation route
- expected failure modes

Do not promote an idea because one backtest looks good. Require route robustness, trade count, drawdown review, and parameter sensitivity.
